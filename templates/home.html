Features

Everything between a push and a page that works

Real health checks

Status codes, response times and timeouts stored for every check. Status is derived, never hardcoded.

Uptime you can explain

Successful checks over total checks for 1 hour, 24 hours and 7 days, with maintenance windows excluded.

Deployment history

Version, commit SHA and outcome for each release, recorded from CI with one command.

GitHub activity

Latest commits, branches and Actions runs through the GitHub REST API.

Searchable logs

Failures, slow responses, recoveries and deployments in one filterable stream.

Response-time charts

One chart per application over an hour, a day or a week, with failed checks marked.

Environment details

Environment name, app and Python versions, plus CPU, memory and disk of the host.

Private by default

Sign-in required for the dashboard and API. Hashed passwords, CSRF protection and rate limiting.
